プライバシーポリシー

制定日: 2026年10月17日

基本方針

「よるのこえ」(以下「本アプリ」)は、AIから生まれたキャラクターと音声で通話できるアプリです。通話の性質上、あなたの声と会話の内容を、外国(米国)の事業者のサービスに送って処理します。本ポリシーでは、どの情報を、どこに送り、どのように扱うかを具体的にご説明します。

収集しない情報

本名、住所、電話番号、メールアドレス、位置情報、連絡先、写真、広告ID(IDFA)は収集しません。キャラクターは、あなたの個人を特定する情報を聞き出さないように設計しています。

外国にある第三者への提供

本アプリは、次の事業者(いずれも米国)に情報を提供し、処理を委託します。これらの事業者に対して、本アプリの機能を提供する目的以外での利用は許諾していません。

米国の個人情報の保護に関する制度について
米国には、日本の個人情報保護法に相当する、すべての分野に共通する連邦法はありません。分野ごとの連邦法や、州ごとの法律(カリフォルニア州消費者プライバシー法など)によって個人情報が保護されています。詳しくは、個人情報保護委員会が公表している外国の制度に関する情報(個人情報保護委員会のウェブサイト)をご覧ください。

提供先が講じている措置について
上記の各事業者は、それぞれのプライバシーポリシーや利用規約、データの取り扱いに関する定めにより、個人情報の安全管理のための措置を講じています。本アプリでは、ElevenLabs での通話音声の保存をオフにし、会話の記録の保持期間を30日に設定しています。OpenAI の API に送信したデータは、OpenAI の方針により、既定ではモデルの学習に使われません。

送信前の同意

最初の通話の前に、アプリの画面(見出し「はじめる前に、ひとつだけ」)で、声と会話が米国の ElevenLabs・OpenAI で処理されることをお知らせし、同意をいただきます。同意いただけない場合、通話機能はご利用いただけません。内容は、設定画面の「AIとの通話について」からいつでも確認できます。

あなたができること(削除・同意の取り消し)

  • 「覚えていること」画面で、覚えていることを1件ずつ・キャラごと・すべて削除できます。
  • 設定画面の「データをすべて削除」で、呼び名・年齢確認と同意の記録・覚えていること・着信の設定・広告の効果の情報・会話の内容を削除できます。これにより、AIへの送信の同意も取り消されます。
  • 月額プランは、iPhone の「設定」→ Apple ID →「サブスクリプション」から解約できます。
  • 上記のほか、保有する個人データの開示・訂正・削除などのご請求は、下記のお問い合わせ先までご連絡ください。

トラッキングについて

本アプリは、他社のアプリやウェブサイトのデータと結び付けて広告に使うこと(トラッキング)はしません。広告IDは使用しません。

年齢について

本アプリは18歳以上の方を対象としています。18歳未満の方はご利用いただけません。

ポリシーの変更

本ポリシーは、必要に応じて変更することがあります。重要な変更がある場合は、アプリ内またはこのページでお知らせします。
